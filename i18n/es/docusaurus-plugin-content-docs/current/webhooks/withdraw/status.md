Este endpoint permite recuperar con detalle una solicitud de retiro creada previamente. Aunque se usa comúnmente para verificar el "estado del retiro", devuelve el objeto completo con toda la información vital de la transacción.

---

## Endpoint
- **Método:** <span className="badge badge--success">GET</span>

```bash title="URL del endpoint"
https://api.xgateglobal.com/withdraw/ID_TRANSACTION/details
```

:::warning[Importante]
El valor **ID_TRANSACTION** en la URL hace referencia al `_id` del retiro generado por XGate en el momento en que se creó la solicitud.
:::

---

## Solicitud

### Encabezados obligatorios

| Encabezado      | Valor               | Descripción                                            |
| :-------------- | :------------------ | :----------------------------------------------------- |
| `Authorization` | `Bearer <tu_token>` | Token JWT de autenticación obtenido al iniciar sesión. |

## Respuestas

### Éxito (200 OK)

La transacción fue encontrada. La estructura de los datos devueltos varía según el tipo de operación (Fiat o Cripto).

**1. Retiro FIAT (BRL):**

### Descripción de los campos

*Nota: La estructura de la respuesta es dinámica. Los retiros puramente Fiat usan el objeto `currency`. Los retiros puramente Cripto usan `cryptocurrency`. Los retiros de conversión (Cripto ➔ Pix) devuelven ambos.*

| Campo                | Tipo     | Descripción                                                                                                                                                                                                                                                            |
| :------------------- | :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `_id`                | `string` | ID único de la transacción generado por XGate.                                                                                                                                                                                                                         |
| `customerId`         | `string` | ID del cliente asociado a la transacción en XGate.                                                                                                                                                                                                                     |
| `externalId`         | `string` | *(Opcional)* El ID del pedido en su sistema, si se envió cuando se creó el retiro.                                                                                                                                                                                     |
| `status`             | `string` | Estado general de aprobación/procesamiento del retiro en la plataforma de XGate (por ejemplo, `APPROVED`).                                                                                                                                                             |
| `generatedReceiptAt` | `string` | Fecha y hora exactas en que se generó el comprobante de la transacción (formato ISO 8601).                                                                                                                                                                             |
| `currency`           | `object` | *(Condicional)* Datos financieros de la operación Fiat (Pix o conversiones). Devuelve propiedades como el estado de pago (`status`), el monto pagado/convertido (`amount`), la moneda (`name`) y el método de destino (`type`).                                        |
| `cryptocurrency`     | `object` | *(Condicional)* Datos de la operación Cripto (Cripto o conversiones). Devuelve el estado de la transferencia en la red (`status`), el monto descontado (`amount`), los datos del token (`name`, `symbol`, `coinGecko`) y los detalles de la red (`blockchainNetwork`). |

### Errores comunes

| Estado  | Mensaje                 | Causa probable                                                                                        |
| :------ | :---------------------- | :---------------------------------------------------------------------------------------------------- |
| **401** | `Unauthorized`          | • Token inválido o caducado.<br /> • Encabezado inválido o no proporcionado.<br /> • IP no permitida. |
| **404** | `Not Found`             | • El ID de transacción proporcionado no es válido.<br />• El retiro no existe en el sistema.          |
| **500** | `Internal Server Error` | Error interno del servidor. Contacte con soporte.                                                     |

## Cómo usar

Aunque la forma más eficiente de hacer seguimiento de los retiros es mediante los **webhooks**, esta ruta de consulta es un endpoint esencial de lectura para mantener su sistema.

### Casos de uso comunes

Usará este endpoint principalmente en las siguientes situaciones:

1. **Conciliación y auditoría:** Confirmar si el monto (`amount`), los datos de la red (`blockchainNetwork`) o el destinatario (`document`/`wallet`) de un retiro procesado por XGate coinciden exactamente con su base de datos interna.
2. **Recuperación ante fallos (fallback):** Si su servidor se cae y pierde la recepción de un webhook, puede crear una rutina (CRON) que consulte los retiros "Pending" usando este endpoint para actualizar los estados perdidos.
3. **Atención al cliente (CS):** Consultar los datos de un retiro específico en tiempo real para ayudar a un cliente final que está cuestionando el progreso de un retiro o el monto de la comisión de red (`gasFeeAmount`).

### Ejemplo práctico

El propósito principal es verificar el progreso de la transacción. Al consultar el endpoint, se centrará en el campo `status` correspondiente a la operación para determinar qué mostrar a su cliente final.

## Integración

  <TabItem value="js" label="Node.js">
    El ejemplo de integración utiliza la librería `Axios` para realizar la solicitud HTTP.

    **Instalando `Axios`:**
    ```bash
    npm install axios
    ```

    **Ejemplo en JavaScript:**
    ```javascript
const axios = require("axios");

(async () => {
    const email = "email@domain.com";
    const password = "••••••";
    const transactionId = "6a3da740e5***************";

    try {
        const url_api = "https://api.xgateglobal.com";
        
        // 1. Obtener el token de autenticación
        const login = await axios.post(`${url_api}/auth/token`, { email, password });
        
        // 2. Consultar los detalles del retiro
        const { data } = await axios.get(`${url_api}/withdraw/${transactionId}/details`, {
            headers: {
                "Authorization": `Bearer ${login.data.token}`
            }
        });
        
        console.log("Detalles del retiro:", data);
        
        // Lógica dinámica para identificar el tipo de retiro según la respuesta
        let status = "Unknown";
        let mensaje = "";
        let destino = ""; // Se inicia vacío para evitar información falsa o indefinida

        if (data.currency && data.cryptocurrency) {
            // Escenario 2: Conversión (Cripto -> Pix)
            // Leemos el estado desde 'currency' ya que es el endpoint Fiat final entregado al cliente
            status = data.currency.status; 
            mensaje = `Conversión: Salieron ${data.cryptocurrency.amount} ${data.cryptocurrency.name} y pagaron ${data.currency.amount} ${data.currency.name}`;
            if (data.document) destino = `Pix (Doc: ${data.document})`;
            
        } else if (data.cryptocurrency) {
            // Escenario 3: 100% Cripto
            status = data.cryptocurrency.status;
            const rede = data.cryptocurrency.blockchainNetwork?.name || "Desconocida";
            mensaje = `Cripto: ${data.cryptocurrency.amount} ${data.cryptocurrency.name} vía red ${rede}`;
            if (data.cryptocurrency.wallet) destino = `Billetera: ${data.cryptocurrency.wallet}`;
            
        } else if (data.currency) {
            // Escenario 1: 100% Fiat (Pix)
            status = data.currency.status;
            mensaje = `Fiat: ${data.currency.amount} ${data.currency.name} vía ${data.currency.type}`;
            if (data.document) destino = `Pix (Doc: ${data.document})`;
        }
        
        // Formatear la cadena de destino solo si hay datos mapeados
        const sufijoDestino = destino ? ` | Destino: ${destino}` : "";

        // Validar la liquidación de la transacción
        if (status === "PAID") {
            console.log(`[PAGADO] ${mensaje}${sufijoDestino}`);
        } else {
            console.log(`[${status}] ${mensaje}${sufijoDestino}`);
        }

    } catch (error) {
        if (error.response) {
            if (error.response.status === 404) {
                console.error("Error 404: El retiro no fue encontrado en el sistema de XGate.");
            } else {
                console.error(`Error en la API (${error.response.status}):`, error.response.data);
            }
        } else {
            console.error("Error de conexión:", error.message);
        }
    }
})();
    ```
